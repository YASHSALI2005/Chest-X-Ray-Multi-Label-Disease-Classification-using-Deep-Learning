Under the hood

The backend model is a DenseNet121 network fine‑tuned for multi‑label classification on chest X‑rays. It predicts the presence of multiple pathologies per image.

  • Input size: 224×224, RGB, ImageNet normalization
  • Loss: BCEWithLogitsLoss
  • Optimizer: Adam
  • Metric: Macro‑F1 across all labels

How to connect this UI

  1. Expose a REST endpoint in Python (e.g. via FastAPI / Flask) that wraps predict_visualize.py or its core logic.
  2. Accept an uploaded image and a threshold value, then return predicted labels as JSON.
  3. Update app.js to POST the selected image to that endpoint instead of using mock results.
